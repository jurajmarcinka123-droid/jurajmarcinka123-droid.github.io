# Publikovanie Matikárne cez GitHub Pages

Projekt je pripravený tak, aby sa po každom nahratí na vetvu `main` automaticky
zostavil a zverejnil cez GitHub Pages.

1. Na GitHube vytvorte nový verejný repozitár s názvom
   `VAŠE_GITHUB_MENO.github.io`. Ak je vaše GitHub meno `jurajmarcinka123`,
   presný názov bude `jurajmarcinka123.github.io`. Takto bude web fungovať
   priamo na hlavnej GitHub Pages adrese bez ďalšieho podpriečinka.
2. Nahrajte doň celý obsah zdrojového ZIP balíka a zmeny odošlite do vetvy `main`.
3. V repozitári otvorte **Settings → Pages**.
4. V časti **Build and deployment** nastavte **Source** na **GitHub Actions**.
5. Otvorte kartu **Actions** a počkajte, kým sa dokončí proces
   **Publikovať Matikáreň na GitHub Pages**.

Stránka bude dostupná na `https://VAŠE_GITHUB_MENO.github.io/`.

Ak chcete použiť vlastnú doménu, nastavte ju následne v **Settings → Pages →
Custom domain**.
